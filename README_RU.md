# RemoteTouch Desktop 0.7.0

Полноценная Windows-панель управления RemoteTouch. Внутри используется текущий сервер RemoteTouch 0.6.4.

## Быстрый запуск на Windows
1. Установи Python 3.13 (если ещё не установлен).
2. Распакуй папку проекта.
3. Дважды нажми `run.bat`.
4. Нажми «Запустить управление».
5. Подключи телефон к той же Wi-Fi сети и отсканируй QR-код.

Если Windows спросит разрешение брандмауэра, разреши доступ для частных сетей.

## Сборка EXE через GitHub Actions
1. Создай новый пустой репозиторий GitHub.
2. Загрузи в него всё содержимое этой папки.
3. Открой вкладку Actions.
4. Запусти workflow `Build RemoteTouch EXE` через Run workflow.
5. После завершения скачай artifact `RemoteTouch-Windows`. Внутри будет `RemoteTouch.exe`.

## Важно
- Телефон и компьютер должны быть в одной Wi-Fi сети.
- Не делись PIN и полной ссылкой с незнакомыми людьми.
- Не открывай порт 8765 в интернет и не используй публичный Wi-Fi для управления.
- Кнопка «Открыть на ПК» открывает веб-панель на этом компьютере; для телефона используй QR-код или скопированную ссылку.
