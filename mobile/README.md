# RemoteTouch Mobile

Android companion app for RemoteTouch Desktop.

## Build

The APK is built by GitHub Actions with the workflow **Build RemoteTouch Mobile for Android**.

## Connect

1. Start RemoteTouch Desktop on Windows.
2. Copy the full pairing link shown by the desktop app. It includes the PIN.
3. Open RemoteTouch Mobile, paste the link, and tap **Подключить компьютер**.
4. Approve the new device in the Windows app.
5. The existing RemoteTouch control page opens inside the Android app.

The app accepts local HTTP links for a trusted home Wi-Fi network and HTTPS links for internet access. Keep the pairing link private.
